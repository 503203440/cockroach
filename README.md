# 🪳 桌面写实蟑螂 (Desktop Photorealistic Cockroach)

一个基于 C++ 和 GDI+ 打造的 Windows 高度写实桌面蟑螂恶作剧/趣味小程序。

具备写实的照片级标本躯干、生物力学三节带刺腿部步态、双侧独立有机探嗅触角，以及高度逼真的生物运动 AI。采用单文件资源打包技术，编译后仅约 **274 KB**，无需安装、无需附带图片，双击即可绿色运行。

---

## 🌟 核心特性

- **📸 写实照片+动态骨骼混合渲染**：提取真实美洲大蠊标本躯干，结合 6 条三节带刺（Femur/Tibia/Tarsus）动态物理腿部，呈现极高辨识度的桌面写实效果。
- **🦵 生物力学柔和步态 (Biomechanical Gait)**：基于非对称支撑/前跨力学 (`AsymSwing`) 与关节屈伸时差，腿部在前跨时屈膝、蹬地时平滑伸展，彻底消除僵硬机械感。
- **📡 双侧独立随机探嗅触角**：左右两根触角采用独立频率与相位波形叠加，以自然柔和的速度异步摆动，并在停顿探嗅时自动加大甩动弧度。
- **🧠 真实生物行为 AI**：
  - **三阶多态随机停顿**：随机切换短暂顿足 (0.8s-1.5s)、常规探嗅 (1.8s-3.5s) 与深度探歇 (4.5s-7.5s)。
  - **三层屏障防逃逸系统**：包含 180px 软墙预警转向、40px 物理边界硬封堵，以及越界 350px/s 急速应急返场机制，确保蟑螂 100% 在屏幕可视区域内活动。
- **📦 单文件免安装绿色分发 (Portable Single-EXE)**：内置 Win32 RCDATA 资源，将 PNG 图像静态打包入 EXE 内部内存流读取，单文件仅 ~274 KB，极便于分发与传输。
- **⏰ 闲置自动唤醒与托盘控制**：后台静默运行，检测到无鼠标/键盘操作达到设定时间（默认 30 秒）后自动从屏幕边缘爬出；支持系统托盘右键菜单随时召唤或退出。

## ⚙️ 配置文件说明 (`config.ini`)

程序在同目录下读取 `config.ini`：
```ini
# 蟑螂小恶作剧 配置文件
# idle_seconds : 无鼠标/键盘操作多久后出现蟑螂（秒）
idle_seconds = 30
```

## 🛠️ 编译与构建

### 前置要求
- Windows 10 / 11
- Visual Studio C++ 开发环境（包含 `cl.exe` 与 `rc.exe`）

### 一键构建
在项目根目录下双击或在命令行运行：
```cmd
build.bat
```
构建成功后将生成单文件 `cockroach.exe`。
